# Time-Series-with-PyTorch

This is the code repository for the book "Time Series with PyTorch" by Packt Publishing. 

[![Time Series with PyTorch](https://img.shields.io/badge/Time%20Series%20with%20PyTorch-Packt-white)](https://www.packtpub.com/en-de/product/time-series-with-pytorch-9781805120421?srsltid=AfmBOoqPtCyBdAPOtAlY6fo6w20YN8WLHXkTBo_5eIc76vww5xuIzscq)



## Prerequisites

- Python>=3.11
- uv

## How to Run the Code

1. Install the required dependencies using uv:
    ```bash
    uv sync --all-groups
    ```
2. Select the virtual environment created by uv in your IDE or terminal or jupyter.
